# 모바일 규칙

모바일 웹앱에만 적용한다. 여기 없는 내용은 공통 규칙을 따른다.

## 입력 방식
- 터치 영역은 최소 44px (`control-md`). 아이콘만 있는 버튼도 44×44.
- hover에 의존하는 표현을 쓰지 않는다.

## 레이아웃
- 화면 좌우 여백 `space-4`(16px).
- 나란히 둔 금액 카드는 화면 폭 360px 미만에서 위아래로 쌓는다.
- 카드의 `number-lg`는 `clamp(22px, 7vw, 28px)`로 28px에서 22px까지만 줄인다.

## 팝업
- 하단 시트: 아래에서 올라옴, 위쪽 모서리 `radius-xl`.
- 닫기는 바깥 탭 또는 아래로 끌기.
- 칸이 많은 입력 시트는 위로 끌어 전체 화면까지 펼친다.
