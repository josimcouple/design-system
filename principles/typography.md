# 글자

- 글꼴: **Pretendard** (jsDelivr로 불러오기, 없으면 시스템 한글 글꼴).
- 굵기는 400(본문), 500(버튼·라벨), 600(제목·숫자) 세 가지만.
- 금액·숫자는 `number-lg`, 숫자에는 `font-variant-numeric: tabular-nums`를 적용해 자릿수를 맞춘다.

## 글자 스타일

값은 [tokens/tokens.json](../tokens/tokens.json)에 있다.

| 스타일 | 크기 / 줄높이 / 굵기 | 쓰는 곳 |
| --- | --- | --- |
| `number-lg` | 28 / 36 / 600 | 화면의 핵심 숫자(합계, 잔액). 화면당 하나 |
| `title` | 20 / 28 / 600 | 화면 제목 |
| `heading` | 17 / 24 / 600 | 카드 제목, 팝업 제목 |
| `body` | 15 / 22 / 400 | 본문, 목록 항목 |
| `label` | 14 / 20 / 500 | 버튼 글자, 입력창 라벨 |
| `caption` | 12 / 16 / 400 | 날짜, 보조 설명. `ink-muted`와 함께 |
