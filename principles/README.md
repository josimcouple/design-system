# 원칙

모바일과 PC 모두에 적용한다.

1. **색은 두 개만.** 포인트는 `primary`(루미너스 블루) 하나, 그리고 삭제·오류 전용 `danger`(빨강). 주식 손익만 예외로 `stock-up`/`stock-down`을 쓴다. 나머지는 모두 푸른 기가 도는 무채색.
2. **숫자와 내용이 주인공.** 장식과 그라데이션은 넣지 않는다. 구분은 `line` 테두리와 `surface-soft` 면으로 한다. 빛 번짐(`luminous`)은 메인 버튼, 포커스 링, 진행 바에만 은은하게 쓴다.
3. **둥글고 넉넉하게.** 버튼·입력창 `radius-md`(12px), 카드 `radius-lg`(16px), 팝업 `radius-xl`(20px).
4. **같은 일은 늘 같은 모양으로.** 버튼 4종, 팝업 3종 외에는 새로 만들지 않는다.

터치 영역 같은 기기별 규칙은 [platforms/](../platforms/)에 있다.
