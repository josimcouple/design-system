# 색

값은 [tokens/tokens.json](../tokens/tokens.json)에 있다.

| 토큰 | 쓰는 곳 |
| --- | --- |
| `bg` | 앱 배경 (밝은 푸른 회백) |
| `surface` | 카드, 팝업 |
| `surface-soft` | 보조 버튼, 입력창 배경 |
| `line` | 테두리, 구분선 |
| `ink` / `ink-muted` | 본문 / 보조 글자 |
| `primary` / `primary-tint` | 메인 버튼, 선택 상태 / 선택된 항목 배경 |
| `luminous` | 포커스 링, 진행 바, 메인 버튼 빛 번짐 (글자에는 쓰지 않음) |
| `danger` | 삭제 버튼, 오류 메시지 (이 용도로만) |
| `stock-up` / `stock-down` | 주식 상승·수익 (빨강) / 하락·손실 (파랑) |

- 수입·지출 금액에는 색을 쓰지 않는다. `ink` 글자에 `+` / `−` 부호로 구분한다.
- 주식 손익은 한국 관례대로 상승 빨강, 하락 파랑. 가계부 수입·지출과 섞어 쓰지 않는다.
- `primary`는 **한 화면에 꽉 찬 버튼 하나**까지만. 나머지 강조는 `primary-tint`나 `primary` 글자색으로.
- 성공·경고 색은 따로 두지 않는다. 완료는 토스트로 알린다.
- 라이트·다크 두 테마를 모두 제공한다. 색은 항상 토큰 이름으로 쓰고 hex를 직접 쓰지 않는다.
