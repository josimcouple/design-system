# 금액 표시

금액은 자릿수가 늘어도 깨지지 않게 아래 규칙을 지킨다.

- **줄바꿈 금지.** 금액에는 항상 `white-space: nowrap`. 숫자가 두 줄로 쪼개지지 않게 한다.
- **자릿수 정렬.** 모든 숫자에 `font-variant-numeric: tabular-nums`, 목록의 금액은 오른쪽 정렬.
- **이름이 양보한다.** 목록 한 줄에서 공간이 모자라면 왼쪽 항목 이름을 `…`으로 줄이고(`text-overflow: ellipsis`, `min-width: 0`), 금액은 끝까지 보인다.
- **큰 금액은 한글 단위로.** 1억 이상은 `1억 2,345만원`처럼 줄여 쓰고, 정확한 금액은 상세(하단 시트)에서 보여준다.
- **부호와 단위.** 지출은 `−`(빼기 기호), 수입은 `+`, 단위 `원`은 숫자에 붙여 쓴다.
