# 버튼 (4종만)

| 종류 | 모양 | 언제 |
| --- | --- | --- |
| 메인 | `primary` 배경 + `on-primary` 글자, 높이 48 | 화면의 핵심 행동 1개 (저장, 완료) |
| 보조 | `surface-soft` 배경 + `ink` 글자 | 취소, 두 번째 행동 |
| 텍스트 | 배경 없음 + `primary` 글자 | 더보기, 추가 같은 가벼운 행동 |
| 삭제 | `danger` 배경 + `on-danger` 글자 | 삭제 확인 팝업 안에서만 |

- 두 버튼을 나란히 둘 때: **왼쪽 취소, 오른쪽 실행.** 너비는 같게.
- 버튼 글자는 동사 1~3어절: "저장", "내역 추가". "확인"만 쓰지 않는다.
- **아이콘만 있는 버튼**은 누구나 아는 기호에만: 추가(+), 닫기(×), 뒤로(‹), 새로고침. 정사각형, `radius-md`, 화면 읽기용 `aria-label`("입출금 입력")을 반드시 단다. 추가(+)는 메인 버튼 모양(`primary` 배경)으로 둘 수 있다.
- 비활성 버튼 대신, 누르면 무엇이 부족한지 안내한다.
