# 팝업 (3종만)

팝업은 **어느 탭이냐가 아니라 무슨 일을 하느냐**로 고른다. 같은 행동은 어느 화면에서든 같은 팝업으로 연다.

| 종류 | 언제 | 규칙 |
| --- | --- | --- |
| 하단 시트 (Sheet) | 채우거나 고르거나 자세히 볼 때 | 모양은 플랫폼별 (아래 표) |
| 확인창 (Dialog) | 되돌릴 수 없는 일 (삭제, 초기화, 작성 중 닫기) | 화면 가운데, 제목은 질문형, 설명 한 줄, 버튼 2개(취소/실행) |
| 토스트 (Toast) | 완료·실패 알림 | 화면 아래, 2~3초 후 자동으로 사라짐, 한 줄 |

하는 일별로 정해둔 팝업:

| 하는 일 | 팝업 |
| --- | --- |
| 입력·수정 (예: 입출금 입력) | 하단 시트 |
| 목록이나 통계에서 항목 눌러 상세 보기 | 하단 시트 |
| 월·기간·카테고리·계좌 고르기, 필터 | 하단 시트 |
| 삭제, 초기화 | 확인창 |
| 입력 중인 시트를 닫을 때 | 확인창 ("작성 중인 내용이 사라져요") |
| 저장·삭제·동기화 완료 | 토스트 (삭제는 "되돌리기" 텍스트 버튼 포함) |

- 가운데 확인창은 **"정말 할까요?"를 물을 때만** 쓴다. 입력 폼을 가운데 팝업으로 띄우지 않는다.
- 팝업은 2단계까지만: 시트 위에 확인창은 되지만, 시트 위에 시트는 띄우지 않는다.
- 브라우저 기본 `alert()` / `confirm()`은 쓰지 않는다.
